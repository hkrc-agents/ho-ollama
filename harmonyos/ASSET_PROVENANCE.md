# Desktop asset provenance

Source: upstream Ollama at 8a971df3bacec93944ec894f2939fd2567afc5dd, under the upstream MIT license.
The app/title-bar/dock PNG is extracted byte-for-byte from the 256x256 PNG frame of app/assets/app.ico. Tray SVG paths preserve app/ui/app/src/components/Logo.tsx geometry with black/white fills for the status bar.
The static source assets are included for normal HAP builds; no generated build output or private extraction tool is required. The test-client geometric icon comes from the sibling SDK example source.
Ollama names and graphics retain upstream branding boundaries; this community adaptation is not an official upstream release.
